## Design Context

### Users

People signing in and checking their authentication state in this starter application.

### Brand Personality

Simple, neutral, and direct. No organization branding.

### Aesthetic Direction

Minimal login form and a single dashboard status page, as requested. Use existing Geist typography, neutral colors, and restrained spacing.

### Design Principles

- Keep only the controls needed to log in, log out, and check authentication state.
- Show both authenticated and unauthenticated dashboard states.
- Use clear labels, visible focus states, and accessible feedback.
- Avoid logos, promotional copy, sidebars, and decorative imagery.
